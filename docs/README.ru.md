> **KRILIKD** — сборочный проект на базе Android GKI и экосистемы Wild Kernels. Он объединяет root-интеграции, патчи совместимости и инструменты для настройки устройства. Состав зависит от семейства ядра и выбранных параметров сборки.

> [!CAUTION]
> Неподходящее ядро может привести к невозможности загрузки. До установки проверьте семейство **стокового ядра**, совместимость прошивки и размер страницы памяти; сохраните резервные копии затрагиваемых разделов и подготовьте способ восстановления именно для своей модели. Успешная сборка не означает проверенную загрузку или совместимость устройства.

## 📱 Совместимость

В групповом workflow сейчас настроены три целевые сборки **4 KB**, по умолчанию с KernelSU-Next:

| Устройство | Семейство и версия ядра | Уровень патча GKI |
|---|---|---|
| **OnePlus 12 / OnePlus Ace 5** | `android14-6.1.157` | `2025-12` |
| **OnePlus Ace 6** | `android15-6.6.118` | `2026-01` |
| **OnePlus 15 / 15R** | `android16-6.12.69` | `2026-03` |

Для **Ace 5** используется сборка OnePlus 12. Проверяйте её соответствие конкретной прошивке и аппаратной ревизии: одинаковое семейство GKI само по себе не гарантирует загрузку. Число после `android` в имени ядра обозначает ветку GKI и может отличаться от версии Android, установленной на телефоне.

Посмотреть текущее ядро можно в настройках устройства или командой:

```sh
adb shell uname -r
```

Семейство, patch level, размер страницы, root-версию и состав функций **проверяйте у выбранного файла и в BuildInfo конкретного запуска**. Проверки системы сборки не заменяют проверки на телефоне.

## ✨ Возможности

| Возможность | Что даёт | Особенности сборки и устройства |
|---|---|---|
| 👑 **Root** | KernelSU-Next, KernelSU, BakaSU, SukiSU Ultra, KowSU, FinaSU или сборка без root | Выберите реализацию и используйте соответствующий менеджер. Совместимость с SUSFS зависит от варианта. |
| 🛡️ **SUSFS** | Интеграция приватности на стороне ядра для совместимых конфигураций KernelSU | Требует совместимой пользовательской части; не гарантирует прохождение проверок всех приложений. |
| 🧩 **NoMount** | Поддержка метамодуля для работы с монтированием модулей | При выборе поставляется отдельно; используйте метамодуль, совместимый с вашим root. |
| 🔐 **Baseband Guard** | Защита критических разделов и узлов устройств от несанкционированной записи | Работает в сборках, где выбран BBG. |
| 🌐 **Сеть** | WireGuard, BBR/BBRv3, CUBIC, CAKE, IPSet, IPv4/IPv6 NAT, conntrack, CIFS и TTL/HL | Доступность зависит от ядра и пользовательских инструментов; проверяйте итоговую конфигурацию и устройство. |
| 🕵️ **VPN Hide** | Интеграция VPN Hide в ядро | Используйте соответствующий companion-модуль; не устанавливайте поверх `vpnhide-kmod`. |
| 🔌 **USB Arsenal** | Функции USB gadget и режимы ISO/DVD/CD-ROM, где они поддерживаются | Набор режимов зависит от ядра, устройства и прошивки. |
| 🎮 **NTSync** | Примитивы синхронизации, совместимые с API Windows NT | Доступны при выборе функции для поддерживаемого семейства ядра. |
| 📦 **DroidSpaces** | Поддержка контейнеров, включая macvlan при соответствующей конфигурации | Возможности зависят от итогового конфига и пользовательской части. |
| 🔎 **BPF и Perf** | BTF, eBPF, FUSE-BPF и возможности профилирования и трассировки | Наличие в сборке не гарантирует запуск конкретной программы BPF. |
| 🧠 **BORE** | Burst-Oriented Response Enhancer — расширение планировщика CPU поверх EEVDF | Опция для `android16-6.12`; при поддержке доступен переключатель в ядре. |
| 💾 **ADIOS** | Adaptive Deadline I/O Scheduler для накопителей | Опция для `android16-6.12`; выбирается во время работы и не назначается принудительно по умолчанию. |
| 🚀 **Оптимизации** | Отобранные патчи планировщика, памяти, пробуждений, файловых систем и логирования | Применённые и пропущенные патчи отражаются в BuildInfo; фиксированный прирост скорости не обещается. |
| 🔋 **Блокировщик пробуждений ASB · AWL** | Опциональные правила по точным именам источников пробуждения | `android16-6.12`; список правил изначально пуст и доступен root. |
| 🧊 **Re-Kernel** | Передача событий приложений и сети совместимым пользовательским инструментам | Опционально для `android16-6.12`; совместимость сторонних заморозчиков не предполагается. |
| ⚡ **SDP 900 mA** | Опциональная настройка лимита входного тока USB data-порта | `android16-6.12`; фактическое поведение зарядки зависит от устройства и прошивки. |
| 🔧 **Ptrace · Unicode** | Исправления совместимости для подходящих деревьев ядра | Доступность зависит от семейства и исходников. |
| 🧠 **Память и нагрузка** | MGLRU, PSI и возможности, связанные с zram | ASB определяет интерфейсы во время работы; поддержка зависит от ядра. |

**BORE, ADIOS, Re-Kernel, AWL и SDP 900 mA доступны для поддерживаемой ветки `android16-6.12` и не присутствуют автоматически во всех ядрах.** При выборе AWL его список правил изначально пуст. Наличие опции в конфигурации ещё не гарантирует, что соответствующий интерфейс доступен и работает на конкретной прошивке.

В составе определённой сборки ориентируйтесь на её **BuildInfo**, итоговый `.config` и результат проверки на устройстве. Возможности можно включать и отключать при сборке; подробности — в [справочнике функций](features.md) и [интеграции ASB](asb-integration.md).

### 🎛️ Вместе с AutoSystemBoost

[AutoSystemBoost](https://github.com/krilikd-factory/AutoSystemBoost) управляет доступными настройками из пользовательского пространства. Перед применением поддерживаемых настроек ASB проверяет интерфейс, сохраняет исходное значение и считывает результат; на неподдерживаемом ядре отдельные переключатели могут быть недоступны. Блокировка пробуждений по точному имени требует соответствующего интерфейса ядра и заданных пользователем правил.

### 🔍 Сведения о сборке и файлы

| Артефакт | Что внутри |
|---|---|
| 📦 **AnyKernel3** | ZIP ядра для установки выбранной сборки |
| 📋 **BuildInfo** | Итоговый `.config`, происхождение исходников, возможности, решения по патчам и проверки |
| 📌 **Pins** | Точные ревизии компонентов и шаблон проверки на устройстве |
| 🧩 **Companion-модули** | Соответствующие VPN Hide и NoMount, когда они выбраны |
| 🛠️ **Rejects** | Не применившиеся части патчей, если они появились при сборке |

Исходники, ревизии компонентов и набор функций фиксируются для каждого запуска. Новые upstream-патчи проходят рассмотрение; кандидатная сборка автоматически не считается проверенной на телефоне. Подробности — в [руководстве по сборке](build-from-fork.md).

## 📥 Скачать и установить

1. Выберите ZIP для своей модели и стоковой ветки GKI в [группе ASB](https://t.me/AutoSystemBoost) или в артефактах подходящего [запуска сборки](https://github.com/krilikd-factory/KRILIKD-kernel/actions/workflows/asb-kernel-topic.yml). Для скачивания артефактов GitHub может потребовать вход; артефакты имеют срок хранения.
2. Проверьте параметры сборки и подготовьте резервные копии и способ восстановления, подходящие вашей прошивке и схеме разделов. Способ отката зависит от устройства и способа установки — универсальный набор разделов не предполагается.
3. Установите **AnyKernel3 ZIP** подходящим для устройства способом. Если сборка требует отдельного метамодуля или менеджера, используйте соответствующие ей файлы и следуйте их инструкциям.
4. После перезагрузки проверьте версию ядра, root, связь, звук, камеру и остальные нужные функции. При проблеме сохраните журнал диагностики и, если доступен, `console-ramoops`.

[Инструкция по установке](installation.md) · [Kernel Flasher](kernelflasher.md) · [После установки](post-install.md)

> VPN Hide, встроенный в ядро, использует совместимый companion-модуль. Не устанавливайте поверх него `vpnhide-kmod`. NoMount поставляется отдельным метамодулем, когда он выбран для сборки.

## 🏗️ Собрать своё

Откройте **Actions → [Build Kernels](https://github.com/krilikd-factory/KRILIKD-kernel/actions/workflows/main.yml) → Run workflow** и выберите конкретные семейство, patch level, root-вариант и функции. Для начала не выбирайте `All`: это запускает множество сборок. Workflow **[KRILIKD · ASB group build](https://github.com/krilikd-factory/KRILIKD-kernel/actions/workflows/asb-kernel-topic.yml)** готовит три указанных выше семейства, поддерживает выбор root и отключение функций; публикация в Telegram управляется отдельным параметром и требует настройки секретов.

Для анализа результата сохраняйте артефакты **AnyKernel3**, **BuildInfo** и **Pins**. В них находятся сведения об исходниках, выбранных компонентах, итоговой конфигурации и проверках сборки. Сборка кандидата не становится проверенной на устройстве автоматически. Подробный порядок — в [руководстве по сборке](build-from-fork.md).
